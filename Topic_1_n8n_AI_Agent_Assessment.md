# Topic 1 Assessment
## Setting Up the n8n Advanced AI Agent Environment

## 1. Assessment Overview

This assessment evaluates your ability to configure a secure n8n AI Agent environment, connect Large Language Model (LLM) credentials, assemble and configure an AI Agent workflow, execute a successful chat request, and validate execution using the n8n debugger. The assessment is based on the provided Requirement Document and Implementation Guide.

## 2. Assessment Objective

Demonstrate the ability to build, configure, execute, and validate a functional n8n AI Agent workflow using secure credential management, model configuration, workflow execution, and execution monitoring.

## 3. Prerequisites

- Review the Requirement Document before starting.
- Review the Implementation Guide.
- Have access to an active n8n instance.
- Have an OpenAI or Anthropic API key with available credits.
- Have a GitHub account for source code submission.

## 4. Assessment Tasks

### Exercise 1 - Access the n8n Workspace
Open a new workflow in an active n8n instance.

### Exercise 2 - Configure Secure LLM Credentials
Create and verify OpenAI or Anthropic credentials.

### Exercise 3 - Build the AI Agent Workflow
Create: When Chat Message Received -> AI Agent -> Chat Model.

### Exercise 4 - Configure the Chat Model
Select credential, choose a model, Temperature = 0.0, Max Tokens = 500.

### Exercise 5 - Execute and Validate
Run the prompt 'Hello, please introduce yourself in exactly one sentence.' and verify successful execution using the debugger.

## 5. Practical Assessment Checklist

- [ ] n8n Workspace Accessed

## 6. Assessment Success Criteria

- Configure secure LLM credentials.
- Build a complete AI Agent workflow.
- Configure model parameters correctly.
- Execute and verify a successful workflow.
- Explain token usage, credential security, and execution lifecycle.
